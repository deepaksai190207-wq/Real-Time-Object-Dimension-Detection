# Real-Time Object Dimension Detection

This project detects and measures object dimensions in real time using OpenCV and Python.

## Features
- Real-time object detection
- Dimension measurement
- OpenCV image processing
- Camera integration

## Technologies Used
- Python
- OpenCV
- NumPy

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
python main.py
```

## Output
Displays object width and height in real time.
